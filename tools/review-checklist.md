# 검사 프로세스 — 세 관점

> 스토리를 쓰거나 질문지를 만들거나 게임 흐름을 손대면 **매번 이 셋을 돌린다.**
> 2026-08-24 도입. 첫 실행에서 실제 버그 1건 + 설계 문제 8건이 나왔다.

## ① 스토리 작가 관점

- [ ] **인물이 이미 아는 것을 다른 인물이 또 알려주지 않는가** (정보 중복 → 긴장 하락)
- [ ] 설정이 앞뒤로 맞는가 — 특히 **기억·신체**처럼 세계관 근간에 닿는 것
- [ ] ★**고치는 방법이 문제 크기에 맞는가.** 대사 한 줄로 될 일에 장면을 넣지 말 것.
      장르 관습으로 암묵 처리하는 게 정답인 경우가 많다 (언어가 그랬다)
- [ ] 같은 감정 표현이 몇 번 반복되는가 (3회 넘으면 무뎌진다)
- [ ] 복선이 회수되는가, 회수 시점이 너무 이르지 않은가
- [ ] 대사가 그 인물의 성격·처지에서 나올 수 있는 말인가

## ② 미연시 전문가 관점

- [ ] **정답이 너무 뻔하지 않은가.** good/bad 가 한눈에 보이면 선택의 긴장이 없다
- [ ] 선택지가 전부 같은 모양(3지선다·good/ok/bad)으로 굳지 않았는가
- [ ] **수위가 튀는 질문이 단계 제한 없이 나오지 않는가** (첫 만남에 갑옷 끈?)
- [ ] 같은 질문이 반복 노출되는가 (본 것 재출현은 몰입을 깬다)
- [ ] 호감도가 **오르기만 하는가.** 내려갈 수 있어야 관계에 긴장이 생긴다
- [ ] 히로인의 성격(MBTI)이 정답 판정과 실제로 연결되는가

## ③ 게임 개발자 관점

- [ ] **보상 코드가 실제로 도는가** — 조건 분기에 걸려 안 도는 경로가 없는가
- [ ] 게이트(호감도·레벨)를 **의도치 않은 우회로 뚫을 수 있는가** (선물만 사서 스토리 스킵 등)
- [ ] 재화 획득량 대비 소모처 가격이 **반복 횟수로 몇 번인가** (지루함의 정체)
- [ ] 세이브/로드로 리롤 가능한 랜덤이 보상에 걸려 있는가
- [ ] 상한·하한에서 표시가 깨지지 않는가
- [ ] 새 필드를 추가했을 때 **기존 경로가 죽지 않는가** ← 이번 버그가 이것
